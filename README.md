# Lab1

Лабораторная работа №1: освоение базового ML-пайплайна на табличных данных.

Студент: Григорьев Глеб Алексеевич, группа М80-102БВ-25.

## Состав проекта

- `lab1.ipynb` - основной Jupyter Notebook с EDA, предобработкой, feature engineering, train/validation/test split, Linear Regression и SGD Logistic Regression;
- `data/student_lifestyle_100k.csv` - исходный датасет;
- `requirements.txt` - минимальные зависимости для воспроизведения.

## Запуск

```bash
python3 -m pip install -r requirements.txt
jupyter notebook lab1.ipynb
```

Ноутбук уже выполнен и содержит ключевые таблицы, графики, метрики и итоговый отчёт.
