# Student Lifestyle Predictor

ML-проект для предсказания академической успеваемости и риска депрессии студентов на основе их образа жизни.

---

## О проекте

Проект решает две задачи машинного обучения на датасете из 100 000 студентов:

- **Регрессия** — предсказать академическую успеваемость (CGPA, шкала 0–4) по lifestyle-признакам: сон, учёба, физическая активность, уровень стресса
- **Классификация** — определить риск депрессии (Depression: 0/1) по тем же признакам

Реализован полный ML-пайплайн: от аудита сырых данных и feature engineering до подбора гиперпараметров и финальной оценки моделей на отложенной тестовой выборке.

## Ключевые особенности

- **Защита от data leakage** — все параметры предобработки (медиана, границы IQR, среднее и std) вычисляются только на train и применяются к val/test
- **Кастомный трансформер** — `IQRClipper` реализован через `BaseEstimator + TransformerMixin`, интегрирован в Pipeline
- **Feature Engineering** — создано 6 новых признаков: `Daily_Load_Hours`, `Free_Hours`, `Study_to_Screen_Ratio`, `Sleep_Deviation_8h`, `Study_Sleep_Product`, `Stress_Sleep_Product`
- **Работа с дисбалансом классов** — `class_weight="balanced"`, акцент на F1/ROC-AUC вместо accuracy
- **Подбор гиперпараметров** — перебор learning rate `[0.0005, 0.002, 0.01]` и epochs `[20, 80, 160]`
- **Анализ переобучения** — кривые обучения ROC-AUC и F1 по эпохам на train/validation
